## 1. 위치정보 이용 (필수)

**무엇을 쓰나요**
- 차량 내비게이션이 알려 주는 현재 위치(위도·경도)

**어디에 쓰나요**
- 근처 충전소 목록을 보여 줄 때: 현재 위치(위도·경도)를 서버로 보내 반경 안의 충전소를 찾습니다. 이 좌표는 결과를 계산하는 데만 쓰고 위치 이력으로 데이터베이스에 저장하지 않습니다. 다만 요청을 처리하다 오류가 나면 오류 로그에 좌표 등 요청 값의 일부가 남을 수 있습니다(아래 2의 운영 로그).
- 충전이 끝났을 때 충전소에서 충전했는지 판정할 때: 판정은 기기 안에서 합니다. 충전소에서 충전했으면 서버에는 **충전소 ID만** 보내고 좌표는 보내지 않습니다.
- 충전소 밖에서 충전한 기록은 서버로 보내지 않고 이 기기에만 둡니다.

**보관**
- 서버 데이터베이스에는 위치 좌표를 저장하지 않습니다. 충전 기록에는 충전소 ID만 남습니다.
- 운영 로그는 아래 2의 보관 기간을 따릅니다.

## 2. 개인정보 수집·이용 (필수)

**이름·전화번호·이메일·차대번호·계정은 입력받지 않습니다.** 앱을 설치하면 무작위 번호(가명 ID)를 하나 만들어, 이 번호로만 기록을 구분합니다. 서버에는 이 번호의 해시값만 보냅니다. 다만 서버에 접속하는 과정에서 아래 표의 운영 로그(접속 IP 주소 등)가 생깁니다.

| 수집 항목 | 목적 | 저장 위치 |
|---|---|---|
| 가명 ID(설치마다 만든 무작위 번호의 해시) | 내 기록 구분, 동의 철회 시 삭제 | 서버 |
| 충전소 ID, 충전 시작·종료 시각, 시작·끝 배터리 잔량(%), 계산한 평균 충전 속도(kW), 결과(인증 충전/충전 실패) | 충전소별 인증 충전 수·평균 속도·실패 수·차슐랭 점수 계산, 내 충전 기록(S6) | 서버 |
| 리뷰 별점·태그 | 충전소 평가 | 서버 |
| 동의한 약관 판 번호, 동의 시각, 철회 시각 | 동의 기록, 철회 뒤 늦게 도착한 기록 차단 | 서버 |
| 운영 로그: 접속 IP 주소, 요청 시각·경로, 처리 결과, 오류가 나면 요청 값의 일부(좌표 포함 가능) | 서비스 운영·보안·오류 확인 | 서버 운영 로그(Supabase) |
| 차종(배터리 용량) | 평균 충전 속도 계산 | 이 기기 |
| 충전소 밖 충전 기록 | 내 충전 기록(S6)에 표시 | 이 기기 |

**다른 사람에게 보이는 것**
- 충전소별 집계(평균 별점, 인증 충전 수, 계산 평균 속도, 최근 실패 수, 차슐랭 점수)만 보입니다. 누가 언제 충전했는지는 보이지 않습니다.

**보유 기간**
- 동의를 철회하면 즉시 삭제합니다(아래 3).
- 철회하지 않으면 서비스를 운영하는 동안 보관하고, 서비스를 끝내면 30일 안에 모두 삭제합니다.
- 운영 로그: 지금 쓰는 Supabase 무료 요금제의 API·데이터베이스 로그 보관 기간은 1일입니다(Supabase 정책). 위 서비스 기록과 따로 관리됩니다.

**처리 위탁·국외 이전**
- 서버 운영을 Supabase에 맡깁니다(Supabase Pte. Ltd., 운영·기술 지원은 Supabase, Inc.). 맡긴 일: 데이터베이스·서버 운영, 운영 로그 보관.
- 국외 이전: 위 표에서 저장 위치가 "서버"·"서버 운영 로그"인 항목은 국외에서 처리됩니다.
  - 이전 국가: 데이터베이스는 호주(Supabase 시드니 리전), 운영 로그는 EU(Supabase 안내에 따름). 운영·기술 지원 과정에서 데이터베이스 리전 밖에서 처리될 수 있습니다.
  - 이전 시기·방법: 앱이 서버에 기록을 보내거나 조회할 때마다 암호화된 통신(HTTPS)으로 보냅니다.
  - 이전받는 자: Supabase(연락 창구는 supabase.com/privacy 안내를 따름)
  - 이용 목적·보유 기간: 위 표의 목적과 위 보유 기간과 같습니다.
  - 거부 방법과 효과: 동의하지 않거나 철회하면 국외 이전도 멈춥니다. 이 경우 앱을 쓸 수 없습니다(서버 기록이 이 서비스의 핵심이라서).
- 제3자에게 제공하지 않습니다.

**동의하지 않을 권리**
- 두 필수 동의를 거부할 수 있습니다. 거부하면 앱을 쓸 수 없습니다(충전 기록이 이 서비스의 핵심이라서).

## 3. 동의 철회와 삭제

- 설정에서 언제든 동의를 철회할 수 있습니다.
- 철회하면 즉시 기록을 멈추고, 서버에 있는 이 가명 ID의 충전 기록·리뷰를 **바로 완전히 삭제**합니다. 충전소 점수는 남은 기록으로 다시 계산됩니다.
- 통신이 안 되면 삭제 요청을 기기에 저장해 두고, 성공할 때까지 다시 보냅니다.
- 운영 로그는 서비스 기록과 따로 관리되어 철회로 바로 지워지지 않고, 위 2의 운영 로그 보관 기간을 따릅니다.
- 기기에 있던 기록(차종, 충전소 밖 기록)도 함께 지웁니다.
- 철회 뒤에도 서버에는 "이 가명 ID는 철회됨"이라는 표시와 동의·철회 시각만 남습니다. 철회 직전 보내던 기록이 늦게 도착해도 저장하지 않기 위해서입니다. 이 표시도 서비스를 끝낼 때 함께 삭제합니다.

## 4. 알아 두실 점

- 차슐랭은 충전소 선택을 돕는 정보입니다. 점수와 실패 기록은 이용자들의 충전 결과를 모은 것이며, 충전기 고장이나 충전소 상태를 보증하지 않습니다.
- "충전 실패"는 충전구를 열었는데 배터리 잔량이 오르지 않았다는 관측 사실이며, 원인(고장·차량·이용자 조작)을 판정하지 않습니다.
- 공모전 시연 빌드의 충전소 기록은 시연을 위한 가상 데이터(시드)입니다.
