## 1. 위치정보 이용 (필수)

**무엇을 쓰나요**
- 차량 내비게이션이 알려 주는 현재 위치(위도·경도)

**어디에 쓰나요**
- 근처 충전소 목록을 보여 줄 때: 현재 위치를 서버로 보내 반경 안의 충전소를 찾습니다. 이 위치는 결과를 계산하는 데만 쓰고 서버에 저장하지 않습니다. 【확인 필요: Supabase 요청 로그에 위치가 남는지, 남으면 보관 기간 — 황준용】
- 충전이 끝났을 때 충전소에서 충전했는지 판정할 때: 판정은 기기 안에서 합니다. 충전소에서 충전했으면 서버에는 **충전소 ID만** 보내고 좌표는 보내지 않습니다.
- 충전소 밖에서 충전한 기록은 서버로 보내지 않고 이 기기에만 둡니다.

**보관**
- 서버에는 위치 좌표를 보관하지 않습니다.

## 2. 개인정보 수집·이용 (필수)

**누구인지 알 수 있는 정보는 받지 않습니다.** 이름·전화번호·이메일·차대번호·계정은 받지 않습니다. 앱을 설치하면 무작위 번호(가명 ID)를 하나 만들어, 이 번호로만 기록을 구분합니다. 서버에는 이 번호의 해시값만 보냅니다.

| 수집 항목 | 목적 | 저장 위치 |
|---|---|---|
| 가명 ID(설치마다 만든 무작위 번호의 해시) | 내 기록 구분, 동의 철회 시 삭제 | 서버 |
| 충전소 ID, 충전 시작·종료 시각, 시작·끝 배터리 잔량(%), 계산한 평균 충전 속도(kW), 결과(인증 충전/충전 실패) | 충전소별 인증 충전 수·평균 속도·실패 수·차슐랭 점수 계산, 내 충전 기록(S6) | 서버 |
| 리뷰 별점·태그 | 충전소 평가 | 서버 |
| 동의한 약관 판 번호, 동의 시각, 철회 시각 | 동의 기록, 철회 뒤 늦게 도착한 기록 차단 | 서버 |
| 차종(배터리 용량) | 평균 충전 속도 계산 | 이 기기 |
| 충전소 밖 충전 기록 | 내 충전 기록(S6)에 표시 | 이 기기 |

**다른 사람에게 보이는 것**
- 충전소별 집계(평균 별점, 인증 충전 수, 계산 평균 속도, 최근 실패 수, 차슐랭 점수)만 보입니다. 누가 언제 충전했는지는 보이지 않습니다.

**보유 기간**
- 동의를 철회하면 즉시 삭제합니다(아래 3).
- 철회하지 않으면 서비스를 끝낼 때까지 보관하고, 서비스를 끝내면 삭제합니다. 【확정 필요: 공모전 종료 후 운영 여부, 종료 시 삭제 시점】

**처리 위탁·국외 이전**
- 서버는 Supabase(Supabase, Inc.)를 씁니다. 【확인 필요: 프로젝트 리전(국외면 이전 국가·항목 고지 필요) — 황준용】
- 제3자에게 제공하지 않습니다.

**동의하지 않을 권리**
- 두 필수 동의를 거부할 수 있습니다. 거부하면 앱을 쓸 수 없습니다(충전 기록이 이 서비스의 핵심이라서).

## 3. 동의 철회와 삭제

- 설정에서 언제든 동의를 철회할 수 있습니다.
- 철회하면 즉시 기록을 멈추고, 서버에 있는 이 가명 ID의 충전 기록·리뷰를 **바로 완전히 삭제**합니다. 충전소 점수는 남은 기록으로 다시 계산됩니다.
- 통신이 안 되면 삭제 요청을 기기에 저장해 두고, 성공할 때까지 다시 보냅니다. 【확인 필요: 차슐랭 #8 재시도 구현 머지 — 이상준】
- 기기에 있던 기록(차종, 충전소 밖 기록)도 함께 지웁니다.
- 철회 뒤에도 서버에는 "이 가명 ID는 철회됨"이라는 표시와 동의·철회 시각만 남습니다. 철회 직전 보내던 기록이 늦게 도착해도 저장하지 않기 위해서입니다. 【확정 필요: 이 표시의 보관 기간】

## 4. 알아 두실 점

- 차슐랭은 충전소 선택을 돕는 정보입니다. 점수와 실패 기록은 이용자들의 충전 결과를 모은 것이며, 충전기 고장이나 충전소 상태를 보증하지 않습니다.
- "충전 실패"는 충전구를 열었는데 배터리 잔량이 오르지 않았다는 관측 사실이며, 원인(고장·차량·이용자 조작)을 판정하지 않습니다.
- 공모전 시연 빌드의 충전소 기록은 시연을 위한 가상 데이터(시드)입니다.
