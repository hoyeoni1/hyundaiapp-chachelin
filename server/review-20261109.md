## 약관용 기술 사실

### 실제 리전

CLI `projects list --output json`에서 프로젝트 `qbdikckaqroxbpacvtqo`의 리전은 `ap-southeast-2`, 상태는 `ACTIVE_HEALTHY`로 확인했다. DB의 주 리전은 **호주 시드니**다. Supabase 공식 리전 목록의 코드와 일치한다.

공식 안내에 따르면 운영 로그·텔레메트리는 선택한 DB 리전 밖에서 처리되며 로그는 EU 데이터센터에 저장된다. 약관에서 처리 위치를 설명할 때 DB 주 리전과 운영 로그의 처리 위치를 함께 고려해야 한다.

근거는 [리전 목록](https://supabase.com/docs/guides/platform/regions)과 [데이터 위치 FAQ](https://supabase.com/legal/privacy-resources/data-residency-and-transfers-faq)다.

### 위치 조회와 요청 로그

- 현재 Android 코드는 좌표를 `POST /rest/v1/rpc/pleos_nearby_stations` 또는 `pleos_nearby_risk`의 JSON 본문으로 보낸다. URL 쿼리에 좌표를 넣지 않는다. 위치를 조회하는 DB 함수는 입력 좌표로 반경을 계산하며 별도의 위치 이력 행을 만들지 않는다.
- Supabase API Gateway의 공개 로그 필드에는 요청 시각·IP 관련 헤더·요청 URL/경로·메서드·상태 코드와 IP 기반 지역 메타데이터가 있다. 공개 필드 목록에 차량 좌표 JSON 본문을 저장하는 필드는 없다. 이는 기본 로그 구조를 근거로 한 판단이다.
- 원격 DB의 현재 설정은 `log_statement=ddl`, `log_min_error_statement=error`, `log_parameter_max_length=-1`, `log_parameter_max_length_on_error=0`이다. 정상 SELECT/RPC 전체를 `log_statement`로 기록하는 설정은 아니며, 오류 SQL과 별도 진단 설정은 추가 검토 대상이다. 이 값은 관리 연결 세션에서 조회한 값으로 역할별 설정과 실제 수집 로그 전부를 증명하지 않는다.
- Free의 API·DB 로그 보관 표준은 공식 요금표상 **1일**이다. 이는 플랫폼 운영·보안 텔레메트리 전체의 삭제 시점을 보장하는 값이 아니다. 플랫폼의 정확한 처리·삭제 범위는 해당 약관과 공급자 확인을 따라야 한다.
- 이번 확인에서는 Logs Explorer의 실제 요청 이벤트를 열람하지 않았다. 따라서 약관의 “어떤 로그에도 원시 좌표가 남지 않는다”는 확약은 아직 할 수 없다. 최종 약관 문구는 대표자가 위 근거를 검토해 확정한다.

근거는 [로그 필드](https://supabase.com/docs/guides/observability/log-field-reference), [Free 요금표](https://supabase.com/pricing), [PostgreSQL 로깅 설정](https://www.postgresql.org/docs/current/runtime-config-logging.html), [데이터 위치·보관 FAQ](https://supabase.com/legal/privacy-resources/data-residency-and-transfers-faq)다.

## core v0.5.2 확인

차슐랭 #30·크루즈 #42의 변경을 확인했다. 잘못된 빌드 설정은 로그를 남기고 Fake로 전환하며, 암호화 파일 복호화 실패·상태 JSON 오류는 빈 상태로 시작하게 한다. 제출 빌드 스크립트에는 공개 키 형식 검사가 있다. 양쪽 core의 소스는 일치한다.

손상된 상태를 초기화하면 그 파일에 있던 전송 대기와 철회 인증을 복구할 수 없다는 한계가 있다. 특히 `EncryptedBackendStore.read()`가 복호화 실패를 null로 반환하는 경로는 `EncryptedBackendStore` 로그에 남고 backend의 `local-storage-reset` 상태에는 잡히지 않는다. 본 점검은 코드 검토와 JVM 회귀 테스트이며 실제 Android Keystore 손상 재현 검사는 포함하지 않는다.
